2. Hasil pemeriksaan

FileJenisTeksBahasaStatus

Centang file yang mau diterjemahkan. Baris merah = file tidak didukung terjemahan (tidak bisa dicentang). File dengan label kuning "Kemungkinan file bahasa" berisi teks yang sudah di-compile — perlu dibongkar dulu di PC.

3. Hasil terjemahan

Belum ada file yang diterjemahkan.

Nama file di dalam ZIP hasil tidak diubah — sama seperti aslinya, struktur folder juga sama. Hanya isi teksnya yang diterjemahkan. File yang tidak didukung disalin apa adanya supaya gamenya tetap jalan.

4. Daftar Teks (mode seperti Game Text Editor)

Semua teks yang akan diterjemahkan ditampilkan sebagai daftar bernomor — seperti Game Text Editor (translate.saveeditonline.com). Hanya teks di daftar ini yang dikirim ke mesin terjemah; kode game (selector CSS, nama variable, tag) tidak disentuh, jadi lebih sedikit bug. Kamu bisa melihat dan mengedit terjemahan apa pun sebelum diterapkan ke file.

Pilih file lalu klik "Tampilkan Daftar Teks".

Cara pakai

  1. Pilih file ZIP/APK, folder, atau banyak file game, lalu klik Periksa Sekarang.
  2. Centang file yang mau diterjemahkan, lalu klik Terjemahkan yang dipilih atau Terjemahkan Semua. Tunggu sampai selesai (file besar butuh waktu; butuh internet karena terjemahan lewat Google).
  3. Klik Cek Hasil untuk memeriksa macro, link, dan tag masih utuh. Kalau ada yang rusak, klik Perbaiki.
  4. Klik Download ZIP terjemahan, lalu ekstrak dan mainkan seperti biasa.
  5. Untuk game Ren'Py (.rpy): setelah diterjemahkan, klik Download tl/id/ (Ren'Py) — hasilnya folder game/tl/id/ (format asli Ren'Py, file asli tidak diubah). Salin folder itu ke folder game/ di game Ren'Py kamu, lalu pilih bahasa di Preferences > Language.
  6. Untuk game Godot (source .gd/.tscn/.tres): klik Buat .po (Godot) — hasilnya file id.po berisi semua teks dari tr() dan properti text di scene (msgstr masih kosong). Terjemahkan file .po itu (upload lagi ke web app, atau pakai Poedit), lalu daftarkan di Godot: Project Settings > Localization > Translations.

Mesin terjemahan: kamus bawaan (istilah game umum, offline) → Google Translate → endpoint Chrome → Microsoft Edge → penerjemah bawaan Chrome (PC, offline setelah model terunduh) → MyMemory. Teks yang sudah diterjemahkan tersimpan otomatis di cache browser — kalau proses dihentikan (tombol Batal) atau browser ditutup, klik "Terjemahkan Daftar" lagi nanti dan teks yang sudah selesai langsung terisi dari cache, hanya sisanya yang diterjemahkan. Kode game (script, style, nama variable) tidak disentuh. Teks di dalam gambar/canvas tidak bisa diterjemahkan.
