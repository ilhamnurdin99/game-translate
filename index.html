2. Hasil pemeriksaan

FileJenisTeksBahasaStatus

Centang file yang mau diterjemahkan. Baris merah = file tidak didukung terjemahan (tidak bisa dicentang). File dengan label kuning "Kemungkinan file bahasa" berisi teks yang sudah di-compile — perlu dibongkar dulu di PC.

3. Hasil terjemahan

Belum ada file yang diterjemahkan.

Nama file di dalam ZIP hasil tidak diubah — sama seperti aslinya, struktur folder juga sama. Hanya isi teksnya yang diterjemahkan. File yang tidak didukung disalin apa adanya supaya gamenya tetap jalan.

4. Daftar Teks (mode seperti Game Text Editor)

Semua teks yang akan diterjemahkan ditampilkan sebagai daftar bernomor — seperti Game Text Editor (translate.saveeditonline.com). Hanya teks di daftar ini yang dikirim ke mesin terjemah; kode game (selector CSS, nama variable, tag) tidak disentuh, jadi lebih sedikit bug. Kamu bisa melihat dan mengedit terjemahan apa pun sebelum diterapkan ke file.

Pilih file lalu klik "Tampilkan Daftar Teks".

Cara pakai

  1. Pilih file ZIP/APK, folder, atau banyak file game, lalu klik Periksa Sekarang.
  2. Centang file yang mau diterjemahkan, lalu klik Terjemahkan yang dipilih atau Terjemahkan Semua. Tunggu sampai selesai (file besar butuh waktu; butuh internet karena terjemahan lewat Google).
  3. Untuk daftar besar, pakai Daftar Teks: pilih file, klik "Tampilkan Daftar Teks", lalu "Terjemahkan Daftar". Kalau sudah selesai, klik Timpa File Asli — file langsung jadi tanpa internet (hanya memakai terjemahan dari daftar), lalu unduh lewat Download ZIP terjemahan. Kalau daftar lebih besar dari 4000 teks, klik "Simpan Proyek" supaya terjemahan tidak hilang saat halaman di-refresh. Setiap baris menampilkan konteksnya (📍 nama passage + kalimat sebelum/sesudah) — teks yang sama di dua passage bisa diterjemahkan berbeda, dan pencarian juga mencocokkan nama passage.
  4. Klik Cek Hasil untuk memeriksa macro, link, dan tag masih utuh. Kalau ada yang rusak, klik Perbaiki.
  5. Klik Download ZIP terjemahan, lalu ekstrak dan mainkan seperti biasa.
  6. Untuk game Ren'Py (.rpy): setelah diterjemahkan, klik Download tl/id/ (Ren'Py) — hasilnya folder game/tl/id/ (format asli Ren'Py, file asli tidak diubah). Salin folder itu ke folder game/ di game Ren'Py kamu, lalu pilih bahasa di Preferences > Language.
  7. Untuk game Ren'Py (.rpy): mau terjemah di Poedit? Klik Buat .po (Ren'Py) — hasilnya file renpy-id.po berisi semua dialog dan teks UI. Terjemahkan di Poedit (atau upload lagi ke web app), lalu klik Download tl/id/ (Ren'Py) untuk memakai terjemahannya.
  8. Untuk game Godot (source .gd/.tscn/.tres): klik Buat .po (Godot) — hasilnya file id.po berisi semua teks dari tr() dan properti text di scene (msgstr masih kosong). Terjemahkan file .po itu (upload lagi ke web app, atau pakai Poedit), lalu daftarkan di Godot: Project Settings > Localization > Translations.
  9. Terjemahan berjalan paralel (3 batch sekaligus) supaya daftar besar lebih cepat — matikan lewat checkbox "Terjemahan paralel" di Pengaturan Lanjutan kalau Google mulai menolak (429). Macro Twine yang hanya mencetak teks (print, button, link, dialog, <<= ...>>, <<- ...>>, linkappend, option) ikut diterjemahkan; macro kode (set, if, widget, dll.) dilewati. Isi <<script>> dan <<silent>> (kode, bukan teks tampil) juga dilewati. Blok verbatim {{{ ... }}} (biasanya CSS/JS/contoh kode) dan passage StoryInit tidak pernah diterjemahkan.
  10. Punya API key sendiri (Groq, OpenRouter, DeepSeek, dll.)? Aktifkan provider custom di Pengaturan Lanjutan — isi alamat API, key, dan nama model, lalu klik "Uji Provider". Provider custom dipakai pertama sebelum mesin gratis; key hanya tersimpan di browser ini.
  11. Kalau hasil terjemahan kehilangan variabel (mis. {gold}, %s, [item]), web app memperbaikinya otomatis: hanya bagian kalimatnya yang diterjemahkan ulang, variabel aslinya disambung kembali (ala Fallowborn). Kalau Google gagal membaca satu batch, dicoba lagi dengan format marker sebelum pindah ke mesin lain.
  12. Penjaga anti-halusinasi (FASE 31): kalau mesin mengembalikan string sampah yang sama untuk banyak teks berbeda, atau class CSS diterjemahkan, hasilnya ditolak dan tidak disimpan — teksnya ditandai gagal supaya bisa diulang lewat mesin lain, bukan merusak game.
  13. QA per teks (FASE 38): setelah diterjemahkan, klik Cek Hasil — tiap pasangan sumber→target diperiksa: variabel, tag, angka, tanda baca akhir, spasi/newline, kata berulang, glosarium, dan rasio panjang (di luar 0,4–2,5x). Baris bermasalah di Daftar Teks ditandai ⚠ dan bisa disaring lewat filter "Bermasalah QA"; laporan lengkap bisa diunduh lewat Download Laporan QA (.md). QA hanya peringatan — Timpa/Download tetap jalan.
  14. Perbaikan variabel otomatis (FASE 39): kalau ada terjemahan yang kehilangan variabel, klik Perbaiki — variabel yang hilang disisipkan kembali dari teks aslinya (di posisi yang sama kalau bisa ditebak), lalu file dibangun ulang, jadi tidak lagi dikembalikan ke asli hanya karena variabel hilang. Saat Timpa File Asli pun variabel diperbaiki dulu sebelum ditempel ke file.
  15. Saran fuzzy (FASE 38): saat "Terjemahkan Daftar", teks yang tidak ada di cache persis dicarikan terjemahan mirip dari cache (≥80%) — ditandai ≈87% dan perlu ditinjau, bukan terjemahan final. Terjemahan yang sudah bersih QA bisa diekspor sebagai memori terjemahan lewat Download TMX (file id.tmx) — bisa dibuka di OmegaT, Trados, atau memoQ, dan dipakai lagi saat game update.

Mesin terjemahan: provider custom (kalau diaktifkan) → kamus bawaan (istilah game umum, offline) → Google Translate → endpoint Chrome → Microsoft Edge → penerjemah bawaan Chrome (PC, offline setelah model terunduh) → MyMemory. Teks yang sudah diterjemahkan tersimpan otomatis di cache browser (4000 terjemahan terakhir) — kalau proses dihentikan (tombol Batal), klik "Terjemahkan Daftar" lagi nanti dan teks yang sudah selesai langsung terisi dari cache, hanya sisanya yang diterjemahkan. Untuk daftar lebih besar dari 4000 teks, klik "Simpan Proyek" (.json) supaya tidak hilang kalau halaman di-refresh. Kode game (script, style, nama variable) tidak disentuh. Teks di dalam gambar/canvas tidak bisa diterjemahkan.
